    How to publish your changes
    1. Click Download rooms.json.
    2. Open Upload files in GitHub and sign in to your account.
    3. Upload the downloaded file, named exactly rooms.json, to replace the existing file. Commit the change.
    4. Wait for the GitHub Pages deployment to finish, then refresh the agenda.

    This editor does not publish directly. Only people with write access to the repository can publish. Download your draft before switching browsers or computers. Your Excel workbook is read locally in this browser. Only the Agenda columns B–F are imported; links and other sheets are not uploaded. Save as .xlsx, or use CSV UTF-8 for the tabular editor format.
